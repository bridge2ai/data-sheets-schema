# Historical GPT-5 assistant prompts

The creation prompt `d4d_assistant_create.md` is retired under the owner's
standing generality rule (G1 F16). It remains as historical provenance and must
not launch new metadata generation. The legacy reference implementation
`src/schema_extract/process_d4d_claude_API_temp0.py` and the Makefile's legacy
GPT-5 extraction entry point refuse new execution.

For new generation, select a declaring source manifest and follow the
[registered shared-generation protocol](../../../../docs/shared-generation-api-v1.md).
Select the model and runtime through that protocol's registration.

`d4d_assistant_edit.md` is a separate historical editing instrument; its
presence does not authorize the retired creation workflow. Preserve existing
records and their recorded prompt identity.
