# Historical Claude Code prompts

The creation prompts `d4d_deterministic_create.md` and
`d4d_generate_from_sources.md` are retired under the owner's standing generality
rule (G1 F16). They remain here as historical provenance and must not launch new
metadata generation. The associated legacy Python entry points refuse before
imports or output writes.

For new generation, select a declaring source manifest and follow the
[registered shared-generation protocol](../../../../docs/shared-generation-api-v1.md).
Current interactive command selection is documented in the
[command index](../../../../.claude/commands/README.md).

`d4d_deterministic_edit.md` is a separate historical editing instrument; its
presence does not authorize the retired creation workflow. Existing records,
receipts and prompts retain their recorded identity.
