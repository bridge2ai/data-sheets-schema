## What "api" means in the code

Definition checked: api = MONOLITHIC: one model call whose input is the prompt, the full LinkML schema and the input documents concatenated with separators.

- Phases (`api_runner.PHASES`): full, core, audit, reconcile_full, reconcile_core, report; derived without a model call: core, reconcile_core; model phases: full, audit, reconcile_full, report.
- Schema sent: schema digest (schema_digest.digest_text).
- Follow-up turns: full_readdress: PHASE_INSTRUCTIONS; report_regate: PHASE_INSTRUCTIONS; readdress: build_readdress; repair: build_repair
- Agentic step: the audit phase requires the registered native batch from renderer 20 (default renderer when none is registered: 8 for the API runtime, 7 for an agentic one); agentic runtimes that render the same conditions: Claude Code, Claude Code (direct), Codex CLI.
