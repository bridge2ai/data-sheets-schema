## Changes

- #1408: backfill tests discovered and explicitly selected chunk manifests
  separately, under both renderer versions. It writes only an exact request
  hash match; an input attestation is not proof that the launcher specified
  that sidecar explicitly.
- #1409: a durable snapshot index records the active generation, input
  identities, logical phase names, actual filenames and SHA256 values.
  Restarting archives the previous index and retains every old snapshot.
  Resume, receipt joins and report checks use the same selected, verified
  phase evidence. A newer unregistered filename cannot replace it. Legacy
  continuation can adopt only hash-attested snapshots from its matched
  provenance record; ambiguous evidence requires recovery or explicit restart.
- #1410: the entire delivered full response is flushed to disk and linked to
  its billed usage ID and generation before receipt parsing or re-addressing.
  A changed manifest can still stop continuation without discarding a paid
  response.
- #1411: canonical custom version-2 chunk rules emitted by the CLI remain
  usable. Their mapping must still reproduce exactly. Nonpositive window
  bounds are rejected before writing.
- #1412: request verification and review packs share one reconstruction
  helper, including the historical renderer default and explicit chunk
  selection.
- #1413: bundle auditing resolves the selected registry's destinations and
  sidecars. Missing external targets and rebuild failures fail strict audit;
  supported custom rules are checked under their recorded parameters.
  Historical study-only inputs that a checkout lacks stay visibly unchecked.

## Boundary and validation

This changes generation recovery and audit behavior. It starts no scientific
measurement and changes no prior rating, generation artifact, frozen prompt,
or registered source inventory. Renderer version 2 remains named; historical
version-1 requests retain their replay semantics. API and agentic recording
remain covered, with the final full/core artifacts derived through the normal
offline generation path.

The new regressions exercise old versus fresh input bytes across an
interruption, inspect the actual resumed report request, preserve all old
snapshot bytes, reject selected-snapshot tampering, retain a delivered
response when receipt repair is refused, replay both renderers with both
chunk-selection modes, and audit clean, custom, unsupported, stale and missing
external inputs. Network access is blocked in these tests.
