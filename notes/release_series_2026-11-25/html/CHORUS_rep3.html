Collection Process

How was the data associated with each instance acquired?

CHoRUS
CHoRUS Dataset
https://chorus4ai.org/
CHoRUS (Patient-Focused Collaborative Hospital Repository Uniting Standards for Equitable AI) is a multi-modal clinical care dataset generated by the CHoRUS project, one of four data generation projects in the NIH-funded Bridge2AI consortium. The project website describes the CHoRUS project as the collection of multi-modal data across 14 different hospitals, using ongoing and new standardization practices, with tools created to support a cloud enclave. The website's dataset snapshot reports, for the current released dataset, 50,000 patient admissions from ICU, PICU, and NICU, 1.6 billion rows of EHR OMOP data, 7,642 admissions with radiology data, and 23 Tb of waveform data; for the anticipated final dataset it reports 100,000 patient admissions, 9 different data modalities, 14 data contributing hospitals, and 60+ CHoRUS consortium members across 20 different institutions. A September 2025 training-program webinar describes the dataset as multicenter, multimodal and high-resolution, collected retrospectively and under controlled access, with OMOP and telemetry data held in an enclave, clinical notes stored locally except tokens, 1000 images available at that time, and EEG extraction in process at that time. The chorus-ai GitHub organization overview, captured on November 14, 2025, states that the collaboration spans 20 academic centers, of which 14 will contribute as Data Acquisition centers.
