Dataset
The CHoRUS dataset is the multicenter, multimodal and high-resolution clinical care dataset of the CHoRUS project (Patient-Focused Collaborative Hospital Repository Uniting Standards for Equitable AI), one of four data generation projects in the NIH-funded Bridge2AI consortium. The project website describes the CHoRUS project as the collection of multi-modal data across 14 different hospitals, using ongoing and new standardization practices, with tools created to support a cloud enclave. A September 2025 training-program webinar describes retrospective data collection under controlled access, with OMOP and telemetry data in the enclave. The GitHub organization overview captured on 2025-11-14 states that the collaboration spans 20 academic centers, of which 14 will contribute as Data Acquisition centers. The 2022 NIH project abstract describes, as plans, developing capabilities to acquire, standardize, tokenize, store, visualize, and label data such as structured electronic health record data, tokenized unstructured electronic health record data, telemetry and EEG waveforms, imaging, and social determinants of health.

The 2022 NIH project abstract states that the project will standardize data to the OMOP Common Data Model, and the GitHub organization overview states that unified standards will harmonize multi-modal EHR, waveform, imaging, and text data. The project website's snapshot of the current released dataset counts rows of EHR OMOP data.
Semantic mapping

Access Review Process
For participants in the AIM-AHEAD Bridge2AI for Clinical Care Training Program, the September 2025 webinar describes a registration process: participants fill out a registration form with name, email, and institution, and an email is sent once access is granted and compute is provisioned. A ".edu" email address is needed to gain access to the dataset, and program administrators will assist with this access if needed. The GitHub organization overview captured on 2025-11-14 directs access requests to dbold@emory.edu or jared.houghtaling@tuftsmedicine.org.
