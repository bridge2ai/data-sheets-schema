Collection Process

How was the data associated with each instance acquired?

CHoRUS
CHoRUS Dataset
https://chorus4ai.org/
The CHoRUS dataset is a multicenter, multimodal clinical care dataset produced by the CHoRUS project, which the project website describes as one data generation project of four in the NIH-funded Bridge2AI consortium and as the collection of multi-modal data across 14 different hospitals, using ongoing and new standardization practices, with tools the team creates to support a cloud enclave. The project website reports the current released dataset as 50,000 patient admissions from ICU, PICU, and NICU, 1.6 billion rows of EHR OMOP data, 7,642 admissions with radiology data, and 23 Tb of waveform data. The same page gives the anticipated final dataset as 100,000 patient admissions, 9 different data modalities, and 14 data contributing hospitals, with 60+ CHoRUS consortium members across 20 different institutions; the GitHub organization overview states that the collaboration spans 20 academic centers, of which 14 will contribute as data acquisition centers. The 2022 grant abstract stated the aim of acquiring an AI-ready data set from more than 100,000 critically ill patients. The cohort 2 training webinar (September 2025) describes the CHoRUS dataset as retrospective data collection with controlled access.

Mechanism Details
Retrospective data collection (cohort 2 webinar, CHoRUS Dataset slide).
Data contributing sites extract and contribute clinical data to CHoRUS following a step-by-step workflow linked to standard operating procedure (SOP) documents that have undergone an internal validation and review process within the Chorus_SOP repository.
Preprocessing Details
Clinical notes are extracted and tokenized using the OHNLP toolkit.
Validated semantic mappings connect clinical data in various source formats to international standards; a chorus-mapping repository holds documentation and pooled tabular mappings along with an associated clinical validation SOP for contributing to mapping efforts, and the GitHub overview refers to downstream analytics on the mapped and assembled dataset.
