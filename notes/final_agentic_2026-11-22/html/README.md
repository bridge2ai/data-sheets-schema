# HTML previews of the 2026-11-22b agentic datasheets

One file per run: `<PROJECT>_rep<N>.html`, rendered with `d4d render html` from the full
record of label `2026-11-22b_claude-opus-5-5-claudecode-generic-v9_rep<N>`.

These are previews for choosing and reviewing. They are not the canonical HTML under
`data/d4d_html/`; that is regenerated once one replicate per project is selected.

The three CM4AI files were rendered with `--skip-validation`. The renderer's own pre-check
validated those records as `DatasetCollection` and refused them; the records validate as
`Dataset` under the schema (see ../gates/). The other twelve rendered with the pre-check on.
